# Open Pages

<DownloadButton url="https://github.com/espenraugstad/uia-scripts/raw/refs/heads/main/scripts/open_pages.user.js" />

<hr />

This script adds some buttons to the list of pages in Canvas in a course. You can then select one or more pages using the checkboxes, and open all the selected pages in new tabs. Alternatively, there is a separate button to open all pages. 

**Note 1:** Opening all pages may crash the browser if there are many pages in the course.

**Note 2:** Opening multiple new tabs may be blocked by the browser, so you may have to explicitly permit it to open more tabs.
